Module 1: Introduction to Machine Learning

Covers CRISP-DM, the ML workflow, and refreshers on NumPy, linear algebra, and Pandas, applied to the 2026 Car Fuel Efficiency dataset (10,000 vehicle records).

Topics practiced:

Loading and inspecting data with Pandas
Handling missing values (fillna, mode, median)
Filtering and subsetting a DataFrame
Matrix operations with NumPy (transpose, matrix multiplication, inversion) — a first hands-on look at the linear algebra behind linear regression
